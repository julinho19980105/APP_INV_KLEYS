# **App Name**: StiloStack

## Core Features:

- Intelligent Registry & Batch Management: Register items with automated unique codes, multi-price tiers (Fardo, Mayor, Unidad), and time-stamped batch tracking to manage stock entries without conflicts.
- Quad-Image Cloud Storage: Upload and manage up to 4 numbered images directly to Google Drive via AppScript, enabling visual catalogs and easy image sorting.
- Semantic Customer & Product Search: Use an AI-powered search tool for fuzzy, case-insensitive, and accent-insensitive matching for customers (CL-000) and products.
- Dynamic Quoting System: Real-time quote builder with stock-safe quantity validation, automated subtotal calculations, and persistent drafts that don't erase on navigation.
- Three-State Inventory Sync: Manage transactions across 'Active', 'Shipped', and 'Annulled' statuses with automatic stock re-integration for canceled orders.
- Automated Web Catalog Feed: Special database view that auto-syncs products with stock > 0, formatting them specifically for external web catalog integration.
- Instant Export & Bluetooth Printing: Save quotes to Google Sheets and instantly generate shareable image summaries or format data for Bluetooth thermal printers.

## Style Guidelines:

- A sophisticated 'Night Mode' palette based on a Deep Charcoal base (#121214) to represent high-end fashion and logistics.
- Primary accent: Electric Violet (#9F7AEA) for interactive elements; Accent: Cool Slate (#2D3748) for desaturated backgrounds.
- Font pairing: 'Space Grotesk' for high-impact numeric headers (Total Soles/Stock) and 'Inter' for dense administrative table data.
- Minimalist, thin-stroke monolinear icons. Visual image placeholders for products show a small numbered badge (1-4).
- Modern card-based segmentation for categories and collections. Large, 300% sized summary counters for totals to ensure visibility on mobile.
- Micro-interactions for the 'X' clear button and slide-in drawers for viewing detailed product specs and image galleries.
